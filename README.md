# erp-teaching-team

**ERP 教学团** · v1.0.0 · `team`

> ERP teaching team — course, case and lab design for ERP courses


Part of the [Lucewalk Lumen](https://github.com/Lucewalk-Lumen/about-me) collection.


## What it does

- **Selection coach** — helps you pick the ERP system and teaching scope that fits your course
- **Concept & domain coaches** — concept scaffolding and domain deep-dives for lectures
- **Exercise coach** — designs exercises and labs grounded in real enterprise processes
- **Progress coach** — tracks student progress across the semester
- **AI-adoption coach** — integrates AI tools into ERP teaching responsibly

## How it works

- Five coaches cover the full teaching cycle: selection → concepts → domain depth → exercises → progress
- A shared ERP knowledge base plus a pain-diagnosis skill target the classic teaching pain points
- Asset routing keeps case data, lab setups and lecture materials organized across the semester

## Agent roster

| Agent | Role |
|---|---|
| `ai-adoption-coach` | AI 与落地教练 |
| `concept-coach` | 概念教练 |
| `domain-coach` | 业务域教练 |
| `erp-teaching-team-team-lead` | ERP 教学团 - 主讲人（课程主教习） |
| `exercise-coach` | 练习与评卷教练 |
| `progress-coach` | 进度与路径教练 |
| `selection-coach` | 选型与论证教练 |

## Skills

`erp-ai-integration` · `erp-asset-routing` · `erp-knowledge-base` · `erp-pain-diagnosis` · `erp-teaching-method`

## Install

1. Download the package zip from [Releases](https://github.com/Lucewalk-Lumen/erp-teaching-team/releases) or clone this repo;
2. Unzip keeping the `.codebuddy-plugin/` manifest structure intact;
3. Import/register in WorkBuddy (custom connector → trust & enable).
